# Cinematic Orbital Hero Direction — Murati Systems

Use this as visual direction for the next landing-page generation pass. This is a prompt guide, not final copy.

## Goal
Create a high-end first viewport for Murati Systems that feels like an AI-native software/system studio. The user likes a dark innovation hero with a huge glowing orbital or black-hole-like form at the top, sparse stars, centered copy, minimal nav, and one CTA.

## Do Not Copy
- Do not clone the provided screenshot.
- Do not reuse its logo, headline, wording, exact layout, or artwork.
- Keep the same emotional category: cinematic, premium, technical, innovative.

## Image Prompt
Black cinematic technology background for a premium AI-native software studio called Murati Systems. A massive abstract orbital system core enters from the top edge, like a cold cyan luminous ring, black hole, or brushed energy vortex, with fine particle trails and subtle technical texture. Deep black negative space below for centered white typography. Sparse stars and tiny data particles, high contrast, elegant, precise, no purple gradient, no generic robot, no human face, no clutter, no text in the image, no logo. Ultra-wide website hero background, premium SaaS / AI systems aesthetic, realistic cinematic lighting, sharp but restrained, 16:9.

## Motion Layer Idea
- Static bitmap as the hero base.
- CSS/Canvas/Three.js layer for slow-moving particles and a barely rotating orbital glow.
- Mouse parallax only on desktop.
- Reduced-motion mode disables rotation and keeps the image static.

## Landing Copy Candidates
- Systems for the AI-native era
- KI-native Systeme fuer Unternehmen, die schneller bauen wollen
- Websites, Software und Automationen - gebaut mit Agenten-Geschwindigkeit
- Moderne Websites, interne Tools und AI-Workflows fuer serioese Unternehmen.

## Build Notes
- First screen only needs: wordmark, compact nav, CTA, small availability/status pill, headline, subline, one primary CTA.
- Avoid public complex pricing on the hero.
- Add proof chips below the fold: Websites, Internal Tools, Automations, AI Workflows, Technical Management.
