# Art Direction — Murati Systems

## DNA Synthesis
Murati Systems should feel like a founder-led technical studio with the ambition of a modern AI systems operator. The visual direction blends three references:

- Linear-style precision: dark, quiet, engineered UI, restrained motion, credible product surfaces.
- Active Theory / Resn-style proof-by-experience: the first viewport should demonstrate technical confidence, not just describe it.
- 21st.dev / MotionSites-style modern hero craft: polished React/Tailwind layout mechanics, strong above-the-fold impact, animated background systems used with purpose.

## Visual Thesis
The site is not a generic AI agency page. It should make a visitor believe Endrit can build real systems quickly: websites, internal tools, workflow automation, and AI-assisted software. The hero should be cinematic and technical, with Murati visible as the personal trust anchor.

## Palette
- Base: near-black and graphite, not pure flat black everywhere.
- Foreground: white, steel grey, muted cyan.
- Accent: one sharp cold accent, preferably cyan or blue-white.
- Avoid: purple-blue AI gradients as the main identity, beige, orange/brown, decorative blobs, stock AI neon.

## Typography
- Use one strong sans-serif family with tight, professional hierarchy.
- Hero headline can be large and cinematic, but compact interface panels and service blocks must use restrained sizes.
- Monospace is allowed for proof chips, system labels, logs, or workflow details only.

## Layout
- First viewport: wordmark, compact nav, one primary CTA, a strong hero line, short subline, and a visual system signal.
- Below the fold: outcomes/services, proof directions, process, and a serious contact CTA.
- Cards are allowed for repeated proof/service items only; do not nest cards.
- Mobile must keep the visual dramatic without text overlap.

## Motion
- Prefer CSS/canvas particles, orbital rings, interface pulses, or subtle reveal motion.
- Motion must be slow, intentional, and reduced-motion friendly.
- No distracting scroll-jacking or endless busy animations.

## Craft Rubric
- [ ] Murati is visible in the brand within the first viewport.
- [ ] The first screen feels like a custom technology/system visual, not a template.
- [ ] Hero copy explains websites, software, automations, and AI-native workflow without buzzword overload.
- [ ] The CTA is direct and singular: project inquiry, system discussion, or first project.
- [ ] Services are framed as outcomes, not generic feature boxes.
- [ ] Visual system uses restrained cyan/steel/white accents on a dark base, avoiding generic purple AI gradients.
- [ ] Responsive desktop and 390px mobile render with no horizontal overflow or text overlap.
- [ ] Direction can later be rebuilt in Next.js + Tailwind without relying on fragile external assets.
