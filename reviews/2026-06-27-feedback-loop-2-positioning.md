# Feedback Loop 2 — Positioning and Naming

Source: ChatGPT project `Murati Digital`, separate chat `Landingpage IT-Dienstleistungen`, plus web UX sources.

## Useful ChatGPT Takeaways

- The page should not say or imply `Wir bauen Websites`.
- It should say: `Wir bauen digitale Systeme. Eine Website ist nur ein möglicher Einstieg.`
- Strong framing: websites, internal tools, automations, and technical care from one technical partner.
- Naming remains open; interesting options from the brainstorm:
  - `Murati Core`
  - `Corelayer`
  - `Northgrid`
  - `Signal Works`
  - `Orbital Works`
  - `Axiom Systems`
- Team copy should replace solo-founder copy.
- Best WhatsApp CTA direction:
  - `Vorhaben per WhatsApp schildern`
  - `Projekt kurz einordnen lassen`
  - `Systembedarf besprechen`
  - `Technisches Vorhaben anfragen`
